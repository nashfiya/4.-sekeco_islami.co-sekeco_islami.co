## 🌟 Tentang Islami.co
**Islami.co** adalah SuperApp digital komprehensif bagi umat Muslim yang dirancang dengan pendekatan *mobile-first* responsif. Tampilan aplikasi ini mengambil inspirasi desain premium dari poster referensi bernuansa **Deep Charcoal / Obsidian Black** dengan aksen **Radiant Amber Gold**, menghadirkan atmosfer beribadah yang khidmat, tenang, elegan, dan modern.

## 🎨 Makna & Filosofi Logo Islami.co

Logo **Islami.co** memadukan 4 elemen visual utama yang sarat dengan nilai spiritual dan kemajuan zaman:


### 2. Arti & Filosofi Warna:

## 🚀 Fitur Unggulan (10 Modul)

1. **Praying Time (Waktu Shalat)**:
   - Jadwal 5 waktu shalat (Subuh, Dzuhur, Ashar, Maghrib, Isya) + waktu Terbit.
   - Jam digital live WIB dan penanggalan Hijriyah otomatis.
   - Kartu waktu shalat berikutnya dengan hitung mundur (*countdown timer*) jam:menit:detik.
   - Highlight emas pada waktu shalat yang sedang aktif saat ini.
2. **Al-Qur'an dengan Fitur Search**:
   - Pencarian real-time berdasarkan ayat, kata kunci arti, nomor, atau nama surah.
   - Teks Arab khat Amiri berskala nyaman dibaca dengan harakat lengkap.
   - Transliterasi Latin font monospace untuk membantu pelafalan.
   - Terjemahan dinamis dalam 3 bahasa (ID, EN, MS).
   - Audio murottal player preview (Play / Pause).
   - Tombol satu-klik untuk menyalin ayat ke clipboard.
3. **Hadist dengan Fitur Search**:
   - Kumpulan hadits dari Shahih Bukhari, Shahih Muslim, Sunan Tirmidzi, dll.
   - Pencarian instan berdasarkan nama perawi, nomor hadits, maupun topik amalan.
   - Badge derajat keshahihan hadits (*Shahih, Hasan, Muttafaq 'Alaih*).
4. **Doa Harian & Pilihan**:
   - Kumpulan doa ma'tsur: doa tidur, doa bangun tidur, doa masuk masjid, doa orang tua.
   - Dilengkapi penjelasan fadhilah dan keutamaan membaca doa tersebut.
5. **Yasin & Tahlil**:
   - Teks Surah Yasin ayat pembuka lengkap dengan tajwid rapi.
   - Urutan bacaan Tahlil lengkap (Al-Fatihah arwah, Tahlil, Tasbih, Doa Arwah).
   - **Tasbih Digital Interaktif**: Tombol haptic vibrator untuk menghitung tasbih (1 s.d 33/100 kali) lengkap dengan notifikasi kelipatan 33 dan tombol reset.
6. **Masjid Terdekat**:
   - Direktori masjid sekitar dengan indikator jarak (km) dan kapasitas jamaah.
   - Rincian fasilitas (akses difabel, AC, parkir luas, klinik).
   - Tombol langsung navigasi rute Google Maps.
7. **Situs Ziarah Makam Ulama & Auliya**:
   - Panduan ziarah makam Walisongo, Habaib, dan Ulama Nusantara (Syekh Maulana Malik Ibrahim, Sunan Kalijaga, Habib Ali Kwitang).
   - Ringkasan sejarah dakwah, alamat, dan rekomendasi waktu ziarah.
8. **Layanan Service (Cari Ustadz & Khotib Jumat)**:
   - Profil asatidz berkompeten (lulusan Al-Azhar Kairo, UIN, PTIQ).
   - Rating ulasan jamaah, spesialisasi fiqih/khutbah, dan status ketersediaan.
   - Modal form pemesanan langsung untuk jadwal khutbah Jumat atau kajian keluarga.
9. **Layanan Tanggap Jenazah 24 Jam**:
   - Banner darurat responsif di halaman utama.
   - Hotline bebas pulsa panggilan mobil ambulan medis (*1500-999*).
   - Tim pemulasaraan & mandi jenazah syar'i terpisah ikhwan/akhwat bersertifikat MUI.
   - Penyediaan kain kafan lengkap dan pembimbing imam shalat jenazah.
10. **Kompas Arah Kiblat Presisi**:
    - Dial kompas emas interaktif yang mengarah ke 295° NW (arah Ka'bah dari Indonesia/Asia Tenggara).
    - Menampilkan jarak langsung ke Ka'bah di Makkah (7.920 km).
    - Tombol kalibrasi sensor kompas.

## 📱 Sistem Onboarding ala iPhone Setup
Saat aplikasi pertama kali dibuka (atau jika cache dibersihkan), layar akan menampilkan pengalaman onboarding layaknya membuka iPhone atau ponsel pintar baru:
- Sapaan berganti-ganti secara elegan: **"Hello"**, **"Selamat Datang"**, **"Ahlan Wa Sahlan"**, **"Salam Sejahtera"**.
- Pilihan 3 kartu bahasa:
  - 🇮🇩 **Bahasa Indonesia**
  - 🇬🇧 **English**
  - 🇲🇾 **Bahasa Melayu**
- Setelah dipilih, aplikasi akan menyimpan preferensi ke `localStorage` dan bertransisi mulus ke beranda. Pengguna juga dapat mengubah bahasa kapan saja secara instan melalui tombol switcher di header atas.

## 📂 Panduan Mock Data (Terpisah & Mudah Dipelajari)

Agar Anda yang belum memahami konsep mock data dapat mempelajarinya dengan mudah, seluruh data tiruan **dipisahkan secara khusus** ke dalam file:
📁 **`js/mock-data.js`**

### Struktur File:
```
IslamiMockData = {
  prayerSchedule: { ... },   // 1. Data Waktu Shalat
  quran: [ ... ],            // 2. Data Surah & Ayat
  hadith: [ ... ],           // 3. Data Hadist Nabawi
  prayers: [ ... ],          // 4. Data Doa Harian
  yasinTahlil: { ... },      // 5. Data Yasin & Tahlil
  mosques: [ ... ],          // 6. Data Masjid Terdekat
  ulamaGraves: [ ... ],      // 7. Data Makam Ulama
  scholars: [ ... ],         // 8. Data Ustadz & Khotib
  funeralServices: { ... },  // 9. Data Layanan Jenazah
  qibla: { ... }             // 10. Data Arah Kiblat
}
```

> **Cara Menambah / Mengubah Data:**  
> Cukup buka `js/mock-data.js` di text editor Anda. Ubah teks nama, bahasa, nomor ayat, atau tambahkan objek baru mengikuti format yang sudah ada. Aplikasi akan otomatis menampilkan data tersebut tanpa perlu mengubah kode HTML!

## ⚡ Cara Menjalankan Aplikasi (Bun & Node.js)

Aplikasi ini sangat ringan, tanpa build step rumit, dan dapat dijalankan dengan berbagai cara:

### Cara 1: Menggunakan Bun (Sangat Direkomendasikan ⚡)
Jika Anda memiliki [Bun](https://bun.sh) terpasang di komputer Anda:
```bash
# Menjalankan server development Bun
bun run dev
```
Aplikasi akan langsung berjalan di: `http://localhost:3000`

### Cara 2: Menggunakan Node.js
Jika komputer Anda menggunakan Node.js:
```bash
# Menjalankan via Node.js
node server.js
```
atau:
```bash
npm run serve:node
```
Buka browser di: `http://localhost:3000`

### Cara 3: Langsung Buka di Browser (Zero Install)
Anda juga dapat langsung mengklik dua kali file `index.html` untuk membukanya di browser Google Chrome, Edge, Safari, atau Firefox favorit Anda!
