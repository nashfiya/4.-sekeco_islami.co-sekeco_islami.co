# Domain Documentation Layout

This repository uses a single-context domain architecture.

## Glossary

- **Path**: `GLOSSARY.md` (repository root)
- **Role**: Contains defined terms, Islamic terminology rules, data schema terminology, and UI component definitions.

## Architecture Decision Records (ADRs)

- **Path**: `docs/adr/`
- **Naming Convention**: `NNNN-<slug>.md` (e.g. `0001-local-markdown-issue-tracking.md`)
- **Status**: Record key architectural decisions, tradeoffs, and changes in this directory.
