# Triage Labels Mapping

This document maps canonical agent triage roles to labels used in this repository's issue tracking system (`.scratch/` markdown tickets).

| Canonical Role | Local Tracker Label | Description |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Newly created issue waiting for review or classification. |
| `needs-info` | `needs-info` | Missing crucial information or feedback needed from the user. |
| `ready-for-agent` | `ready-for-agent` | Ticket is fully specified and ready for an AI agent to execute. |
| `ready-for-human` | `ready-for-human` | Requires human verification, creative approval, or manual intervention. |
| `wontfix` | `wontfix` | Decided not to implement or out of scope. |
